docs-mcp-server scrape <library> <url> [options]

Scrape and index documentation from a URL or local folder.

To scrape local files or folders, use a file:// URL.
Examples:
scrape mylib https://react.dev/reference/react
scrape mylib file:///Users/me/docs/index.html
scrape mylib file:///Users/me/docs/my-library

Note: For local files/folders, you must use the file:// prefix. If running in
Docker, mount the folder and use the container path. See README for details.
