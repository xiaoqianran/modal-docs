# Modal Brand Kit

Visual essentials for Modal — logos, colors and founder photography for press and partner use. The interactive version of this page lives at https://modal.com/brand.

## Download

[Download the brand kit](https://modal-cdn.com/brand/modal-brand-kit.zip) — a zip with the logos as SVG and PNG, the founder photos and a README with usage notes.

## Logos

Use the lockup first; the mark alone is for square spaces. Keep the original logo colors and proportions. Each logo is an SVG and a 2400px-wide transparent PNG.

## Colors

- **Modal black** — `#040804` — backgrounds and most of every surface
- **Off-white** — `#E3E5E1` — text on black, light bands
- **Modal green** — `#7FEE64` — accents, sparingly
