# 计费

Modal 是无服务器的，这意味着您只需为您使用的计算或[请求](/docs/guide/resources) 付费。无需预订，也没有最短使用时间增量。我们所有产品的最新单位定价可在我们的[定价页面](/pricing) 上找到。

## 计费频率和增量计费

所有工作区均按月计费。在每个计费周期结束时，系统会自动向您收取该周期内产生的 Modal 使用费用（减去任何积分和增量使用费用），以及下一个计费周期的任何订阅费用（仅限非 Starter 计划）。

除了按月计费外，首次超过特定阈值时还会自动向您收取增量使用费。这些费用发生在计费周期内。

## 预算

Modal 支持工作空间级别和环境级别支出预算。请参阅[预算](/docs/guide/budgets) 了解在何处配置它们以及它们如何交互。

## 更新账单信息
要更新您的账单信息，请单击“设置”的[使用情况和账单](/settings/usage) 部分中的“管理付款详细信息”。这将带您进入 Stripe 托管页面，您可以在其中更新您的付款方式和/或账单电子邮件。

请注意，您必须备案付款方式才能使用 Modal。如果您想删除您的付款方式并删除您的工作区，请联系<support@modal.com>。

## 查看发票历史记录

要查看发票历史记录和/或下载收据，请单击“设置”的[使用情况和计费](/settings/usage)部分中的“查看发票”。您应该在 Stripe 托管页面的底部看到“发票历史记录”部分。

## 生成账单报告

我们还提供编程 API，用于将计费报告导出到团队和企业计划级别的工作区。使用 [`modal.billing`](/docs/sdk/py/latest/billing) 或 [`modal billing`](/docs/cli/latest/billing) CLI 中的 API 生成跨特定模态应用程序或其他资源细分的随时间变化的支出的表格报告。
请注意，这些界面生成的详细计费报告会在考虑积分或预订之前显示成本明细，因此总发票成本可能低于这些报告的总成本。

在大多数情况下，尽管可能会出现收集延迟，但 API 查询的数据库中会在几分钟内提供账单数据。如果完整性对于您的用例很重要，我们建议在查询间隔结束后保留​​一个缓冲区。

## 成本归属

我们提供灵活的标签系统，以便您可以对应用程序进行分类，并将工作区中的支出正确归因于不同的团队、项目等。标签是键值对，可以在部署应用程序时设置或分配给已运行的应用程序：

```python
app = modal.App(name="inference-engine", tags={"team": "llm-platform"})
```

通过 API 或 CLI 生成计费报告时，您可以请求在报告输出中包含这些标签。请注意，标签将归因于整个间隔，即使它们是在其中的某个点添加或删除的。如果在该时间间隔内未使用标签名称，则该输出行的标签字典中将不存在该名称。

## 自定义发票
与我们有使用承诺的 [企业计划](/定价) 客户可以使用发票结算、国际银行转账付款方式、拆分发票和其他自定义要求。请联系<sales@modal.com>。
