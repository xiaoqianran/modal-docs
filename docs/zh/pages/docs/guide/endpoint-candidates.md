# 候选端点

[专用端点](/docs/guide/dedicated-endpoints) 提供来自其的流量
**生产**部署。创建**候选**来测试对模型的更改
或重量而不改变生产。每个候选人都有自己的 URL 和
容器。

## 创建候选人

在[仪表板](https://modal.com/endpoints)中打开您的端点，然后打开
**部署**下拉列表并选择**创建候选人**。

一个端点同时最多可以有五个候选者。从以下选择一个型号
与生产任务类型相同的模态库：文本生成或
嵌入。要使用自定义权重，请选择 **自定义权重**，然后提供
拥抱脸部存储库和修订版或模态体积和路径。权重
必须与所选的基本型号兼容；看到
[提供自定义权重](/docs/guide/dedicated-endpoints#serve-custom-weights)。

对源权重的更改不会更新现有候选值。促销
使用与您测试的相同的重量。

候选人从服务配方的自动缩放默认值开始，而不是
生产的设置。

## 测试候选人

在 **部署** 下拉列表中选择候选者并等待配置
完成。将其 URL 从仪表板复制到
[发送测试请求](/docs/guide/endpoints#call-an-endpoint)。考生使用
生产的[模型名称](/docs/guide/endpoints#model-names) 和身份验证
设置。

## 镜像生产流量

流量镜像将生产请求复制给候选者。客户收到
生产的反应；候选答案将被丢弃。

选择一个已配置的候选者，单击“**镜像流量**”，然后选择
要复制的流量的百分比。您可以镜像到多个候选人，每个候选人都有
自己的百分比。要禁用它，请打开镜像控件并单击
**停止镜像**。

镜像请求可以扩展候选者并产生计算费用。

## 晋升候选人

选择候选人并单击“**晋升**”。促销开始新生产
使用候选人的模型、权重和服务配方进行展示。生产
URL 和请求模型名称保持不变。

生产保持其最小、最大和缓冲容器设置及其
放大和缩小窗口。候选自动缩放更改不进行
转向生产。

当推出开始并停止其镜像时，促销会删除候选者
交通。它的 URL 不再可用；其他候选人不变。

要在成功晋升后改回来，请创建并晋升新候选人
使用以前的模型或权重。

## 删除候选人

选择候选人并单击“**删除候选人**”。删除会停止其
容器及其任何镜像流量。生产和其他候选人是
不受影响。

停止端点会停止其所有候选端点。

## 定价

您需要为每个候选人的容器使用的[计算资源](/定价)付费。
缩放至零的候选者不会产生计算费用。
