# 模态用户帐户设置

要在 Modal 上运行和部署应用程序，您需要注册并创建一个用户
帐户。

您可以访问[注册](/signup)页面开始该过程或执行
[`modal setup`](/docs/cli/latest/setup#modal-setup) 在命令行上。

还可以通过 [Okta SSO](/docs/guide/okta-sso) 配置用户，即
您可以请求的企业功能。对于典型用户，您需要注册
使用现有的 GitHub 帐户。如果您有兴趣通过以下方式进行身份验证
其他身份提供商通过 <support@modal.com> 通知我们。

## 注册需要什么 GitHub 权限？

* `user:email` — 为我们提供与 GitHub 帐户关联的电子邮件。
* `read:org`（仅限邀请）- 模态工作区邀请所需。注：这个
  只允许我们查看您拥有哪些组织成员资格
  （[GitHub 文档](https://docs.github.com/en/apps/oauth-apps/building-oauth-apps/scopes-for-oauth-apps)）。
  我们将无法访问任何代码存储库或其他详细信息。

## 我如何更改我的电子邮件？

您可以在[设置](/settings)页面更改您的电子邮件。
