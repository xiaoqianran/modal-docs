# CLI 参考

这是`modal`命令行界面的参考，已安装
与 [`modal`](https://pypi.org/project/modal/) Python 包一起。

## 命令

|  |  |
| --- | --- |
| [`modal curl`](/docs/cli/latest/curl) |将经过身份验证的请求发送到模态端点。 |
| [`modal deploy`](/docs/cli/latest/deploy) |部署模态应用程序。 |
| [`modal serve`](/docs/cli/latest/serve) |通过代码更改热重载来公开 Web 函数。 |
| [`modal shell`](/docs/cli/latest/shell) |在模态容器内运行命令或交互式 shell。 |
| [`modal run`](/docs/cli/latest/run) |运行模态函数或本地入口点。 |## 部署

|  |  |
| --- | --- |
| [`modal app`](/docs/cli/latest/app) |管理已部署和正在运行的应用程序。 |
| [`modal container`](/docs/cli/latest/container) |管理并连接到正在运行的容器。 |
| [`modal endpoint`](/docs/cli/latest/endpoint) |创建和管理 LLM 推理端点。 |

## 存储

|  |  |
| --- | --- |
| [`modal image`](/docs/cli/latest/image) |管理图像。 |
| [`modal dict`](/docs/cli/latest/dict) |管理 `modal.Dict` 对象并检查其内容。 |
| [`modal secret`](/docs/cli/latest/secret) |管理秘密。 |
| [`modal queue`](/docs/cli/latest/queue) |管理`modal.Queue`对象并检查其内容。 |
| [`modal volume`](/docs/cli/latest/volume) |阅读和编辑`modal.Volume`卷。 |

## 入职

|  |  |
| --- | --- |
| [`modal setup`](/docs/cli/latest/setup) | Bootstrap Modal 的配置。 |
| [`modal bootstrap`](/docs/cli/latest/bootstrap) |初始化示例模态应用程序。 |

## 配置

|  |  |
| --- | --- |
| [`modal workspace`](/docs/cli/latest/workspace) |与当前模态工作区交互。 |
| [`modal environment`](/docs/cli/latest/environment) |创建环境并与之交互 || [`modal profile`](/docs/cli/latest/profile) |在模态配置文件之间切换。 |
| [`modal config`](/docs/cli/latest/config) |管理当前配置文件的客户端配置。 |
| [`modal token`](/docs/cli/latest/token) |管理代币。 |
| [`modal skills`](/docs/cli/latest/skills) |安装并更新 Modal 的代理技能。 |

## 可观察性

|  |  |
| --- | --- |
| [`modal billing`](/docs/cli/latest/billing) |查看工作区计费信息。 |
| [`modal changelog`](/docs/cli/latest/changelog) |从 Modal 变更日志中获取发行说明。 |
| [`modal dashboard`](/docs/cli/latest/dashboard) |在 Web 浏览器中打开模态仪表板。 |
