#`modal profile`

在模态配置文件之间切换。

**用法**：

```shell
modal profile [OPTIONS] COMMAND [ARGS]...
```

**选项**：

* `--help`：显示此消息并退出。

**命令**：

* `activate`：更改活动模态配置文件。
* `current`：打印当前活动的模态配置文件。
* `list`：显示所有模态配置文件并突出显示活动的配置文件。

## `modal profile activate`

更改活动模态配置文件。

**用法**：

```shell
modal profile activate [OPTIONS] PROFILE
```

**选项**：

* `--help`：显示此消息并退出。

## `modal profile current`

打印当前活动的模态配置文件。

**用法**：

```shell
modal profile current [OPTIONS]
```

**选项**：

* `--help`：显示此消息并退出。

## `modal profile list`

显示所有模态配置文件并突出显示活动的配置文件。

**用法**：

```shell
modal profile list [OPTIONS]
```

**选项**：

* `--json`
* `--help`：显示此消息并退出。
