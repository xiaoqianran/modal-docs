# 模态文档

> Modal 是一个在云中运行 AI 工作负载的平台，只需最少的
> 配置。主要用例包括人工智能模型训练和推理，
> 高性能批处理作业和沙盒代码执行。它提供
> 快速原型设计、无服务器 API、计划作业、GPU 推理、
> 分布式存储卷和高度可扩展的安全沙箱。

重要提示：

- Modal 的平台针对 AI 用例进行了优化，但它可以支持
  通用云工作流程。
- Modal 是一个无服务器平台，这意味着您只需为使用的资源付费。
  容器在空闲时可缩放至零，并在需要时在几秒钟内启动。
- Modal 提供 Python、Go 和 JavaScript/TypeScript 官方 SDK，以及
  用于与平台交互的功能齐全的 CLI。

您可以在 [https://modal.com] 免费注册并获得每月 30 美元的积分。

这些文档分为三个主要部分：
- _Guide_ 页面解释了 Modal 的功能、原语和工作流程
-_示例_页面包含许多不同人工智能应用程序的教学示例
-_参考_页面提供有关 SDK 和 CLI 的详细信息
