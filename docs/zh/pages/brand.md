# 莫代尔品牌套件

Modal 的视觉要素 — 徽标、颜色和创始人摄影，供媒体和合作伙伴使用。此页面的互动版本位于https://modal.com/brand.

## 下载

## 标志

- 标记：[SVG](https://modal.com/brand/modal-mark.svg)、[PNG](https://modal.com/brand/modal-mark.png)- 锁定·深色单色：[SVG](https://modal.com/brand/modal-lockup-mono-on-dark.svg)、[PNG](https://modal.com/brand/modal-lockup-mono-on-dark.png)

- **莫代尔黑色** — `#040804` — 背景和大部分表面
